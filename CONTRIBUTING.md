# Contributing

1. Use synthetic fixtures only. Never commit customer or personal financial data.
2. Add a failing test before changing deterministic finance behavior.
3. Document the accounting formula and source-field evidence.
4. Preserve the rule that uncertain mappings and currency bases block publication.
5. Run `python -m pytest -q` before submitting changes.

Source profiles must use multi-field signatures and authoritative vendor documentation. Community discussions may motivate test cases but cannot define accounting rules.
